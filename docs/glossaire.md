# Glossaire du projet

> **BROUILLON — à valider par le gestionnaire humain**
>
> **SIMULATION INTERNE. Aucun capital réel. Ce document ne constitue pas une offre de titres, de parts ou de services financiers et ne doit pas être diffusé à aucun tiers.**

| Terme | Définition simple |
|---|---|
| Agent | Composant logiciel ou personne affecté à un rôle défini dans la simulation ; son mandat limite ses données et ses actions. |
| Backtest | Évaluation historique simulée d'une hypothèse à partir de données passées ; elle ne garantit aucun résultat futur. |
| Comité d'investissement simulé | Instance interne qui examine les étapes d'une stratégie de simulation ; elle ne décide d'aucun investissement réel. |
| Comité des risques | Instance interne qui examine les risques, limites, contrôles, incidents et exceptions du simulateur. |
| Conseil juridique externe | Humain consulté ponctuellement pour identifier les questions à soumettre à un avocat ; ce dépôt ne rédige pas d'avis juridique. |
| Cybersécurité | Contrôles destinés à protéger les accès, environnements, dépendances et données autorisés. |
| Données hors échantillon | Données ou période conservées pour évaluer une hypothèse après sa conception, sans les utiliser pour l'ajuster. |
| Gouvernance | Organisation des rôles, responsabilités, droits de décision, contrôles et processus de consignation. |
| Paper trading | Simulation d'opérations sans engagement de capital réel. |
| Portfolio Manager | Rôle qui coordonne les priorités et propositions du portefeuille simulé, dans les limites approuvées. |
| Pull request | Proposition de changement soumise à revue avant intégration dans une branche de référence. |
| Quorum | Nombre ou combinaison minimale de participants requis pour qu'une instance puisse délibérer, à valider humainement dans ce projet. |
| RCCI | Rôle interne de contrôle de conformité et de procédures ; son titulaire et son périmètre restent soumis à validation. |
| Registre | Document structuré qui conserve les entrées datées, auteurs, décisions ou statuts et justifications. |
| Risk Manager | Rôle chargé de challenger et surveiller les risques du simulateur et de signaler les contrôles critiques. |
| Stratégie simulée | Hypothèse de recherche suivie dans le cycle proposition, backtest, validation hors échantillon, paper trading et revue. |
| Validation hors échantillon | Examen d'une hypothèse sur des données non utilisées lors de sa conception. |
| Veto | Blocage ou suspension documenté(e) d'une action lorsque le mandat l'autorise et qu'un contrôle critique le justifie. |
| Revue mensuelle | Réunion interne périodique d'examen des stratégies simulées, incidents, changements, décisions et actions de suivi. |
| Simulation interne | Environnement pédagogique et de recherche sans capital réel, réservé au travail interne défini par le projet. |
